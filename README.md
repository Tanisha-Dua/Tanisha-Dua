### 🧬 [Protein Structure Feature Analysis](https://github.com/Tanisha-Dua/Protein-Feature-Analysis)

Separates **globin** (α-helical) from **immunoglobulin** (β-sandwich) protein folds using simple structural descriptors.

- Python + **PyMOL** pipeline over **100 PDB structures**
- 8 structural features: α-helix %, β-sheet %, molecular weight and more
- **K-Means clustering** in Weka with **99% accuracy**

`Python` `PyMOL` `Pandas` `Matplotlib` `Weka`

### 🌊 [Damped Oscillation Analysis](https://github.com/Tanisha-Dua/Damped-Oscillation-Analysis)

A mathematical study of a **nonlinear mass–spring system** with kinetic friction, applied to seismic isolation.

- State-space **matrix analysis**: eigenvalues, SVD, rank
- **Probability simulation** of the friction coefficient (Monte Carlo, N = 1000)
- **Euler vs RK4 vs ODE45** numerical solvers

`MATLAB` `Linear Algebra` `Probability` `Numerical Methods`
